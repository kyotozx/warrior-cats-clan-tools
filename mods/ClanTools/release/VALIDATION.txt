LIMITS
No physical controller was available for acceptance testing; controller command
routing is implemented, but model checks are not a physical-controller test.
Native HUD portrait caches can retain the previous look until a save reload.
The new-player flow was sampled across WindClan skin -> ThunderClan character;
this does not represent every cross-clan appearance combination or game scenario.
No dynamic clock/weather system was found; lighting uses authored sky presets.
Skin exchange excludes identity, progression, accessories and scars.
Generic third-party settings integration and online/Workshop downloads are not
included in loader API 1. Packages contain executable code, not sandboxed plugins.

REMAINING COVERAGE / LIMITATIONS
Physical Xbox/PlayStation controls, extended flight feel, all terrain/chapter
transitions, sustained gameplay, every appearance preset combination, all items,
all quests/enemies, skeletal den assets, other resolutions and other-mod
compatibility have not been exhaustively tested. Native bindings and controller
routing have model coverage; do not equate that with a physical-controller test.
Some native name lists (including combat turn order), bonds lists and authored
dialogue text retain the original name. There are two companion slots. Followers
can wait at obstacles where native navigation is absent. Crafting acceleration
is active inside the den. Offline-only tools do not modify network sessions.
