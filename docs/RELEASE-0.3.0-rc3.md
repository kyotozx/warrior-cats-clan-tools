# Clan Loader 0.3.0-rc3 with Clan Tools 0.3.0-rc1

First public release candidate for Steam build `24847281` on Windows x64.

## Included

- Clan Loader external manager with original-game fonts and textures, fixed dark styling, clan emblems, package installation/removal, and skin import/export.
- Native in-game Mods menu with keyboard and controller navigation.
- Clan Tools: party management and followers, clan appearance/name editing, player skin library, item feedback, offline admin, map travel, den crafting/workshop, photo tools, keybinds, and FPS controls.
- Tested UE4SS runtime and third-party notices.

Download the complete `ClanLoader-0.3.0-rc3.zip`, extract it, and open `ClanLoader.exe`. Save and close the game before installing or updating. The source archives generated by GitHub are for development.

## Validation and limits

The publication source copy passed 75 Lua suites, three PowerShell suites, five isolated native harnesses, and independent section comparisons for 14 native bridges. The external manager was inspected in the running app. Original artwork/font extraction, cache verification, and mismatched-source rejection were checked against the supported installed game.

See `ClanTools/VALIDATION.txt` inside the bundle for feature-specific live testing and remaining limits. Automated tests do not replace gameplay acceptance. This remains a prerelease, with no claim of compatibility with other game builds or community managers.

No Steam Workshop integration or dynamic weather simulation is included. Native game assets are read from the user's own installation. Personal saves, settings, extracted artwork, and game binaries are not included.
